# 数据与标注

> **核心论断：80% 的工程量在数据，不在模型。**

## 标注分层（成本从低到高）

| 层 | 标注形式 | 降本技巧 |
| --- | --- | --- |
| 检测 / 关键点 | box / 21 点 | 模型预标注 + 人工修正（半自动） |
| 跟踪 | 轨迹 | 检测 + 关联规则自动生成轨迹，人工只修错 |
| 动作 / 事件 | **视频级弱标签** 或时序区间 | 优先弱监督（MIL），区间标注最贵 |
| 商品分类 | 类别标签 | 层次标签 + 检索，避免全量闭集 |

## 最大的难点：正样本稀疏

真实数据里漏扫事件占比极低。破解手段：

1. **合成 / 数字孪生**：用 UE / Unity 造极端场景 + **域适应**（sim→real）。
2. **主动学习**：人工复核结果回流，专挑难例标注。
3. **公开数据预训练**：COCO（检测）、100DOH（手物交互）、Something-Something / Ego4D（动作）、ImageNet（分类）。

## 数据来源与合规

- **真实门店采集**：必须脱敏、去人脸、最小化留存（见[隐私与合规](../engineering/privacy.md)）。
- **合成数据**：可覆盖稀有的漏扫 / 遮挡 / 极端光照，但要做域适应。
- **供应商商品图**：适合初始化分类，但注意域差。

## 数据治理

- 版本化：数据集、标注、切片都要有版本。
- 切片（slice）分析：按门店、相机、时段、商品类拆分评测，找出长尾短板。
- **分布对齐**：训练分布必须 ≈ 部署分布（同一相机视角 / 光照 / 商品）。

## 常见陷阱

1. **只在实验室数据上训** → 现场崩。
2. **忽略类别极不平衡** → 模型只会说"没有漏扫"。
3. **标注不一致** → 不同标注员对"是否漏扫"的判据不同，需要明确标注规范与抽检。
4. **不留测试切片** → 无法诊断长尾。
