# 隐私与合规

## 红线：不做人脸识别

- 人脸 / 生物特征属于**敏感个人信息**，合规成本极高（GDPR 特别类别、国内《个人信息保护法》对生物识别的强约束）。
- 本场景**只需行为，不需要身份**：识别"发生了什么动作"，而非"是谁"。
- 主流厂商（如 Everseen）也以"行为的不是身份的"作为合规卖点。

## 数据最小化

| 措施 | 说明 |
| --- | --- |
| 本地处理优先 | 推理在边缘盒完成，仅上传结构化事件 |
| 只存片段 | 只保留触发事件的短片段，不存全程 |
| 留存期限 | 明确保留周期，到期自动清除 |
| 去标识 | 不关联人脸 / 身份；必要时面部模糊化 |

## 合规框架

- **国内**：《个人信息保护法》《数据安全法》——采集需告知、最小必要、目的限定。
- **欧盟**：GDPR——生物特征为特殊类别数据；摄像头部署需合法基础与告知。
- **美国**：各州监控 / 人脸法规不一（如部分州限制零售人脸）。

## 工程落地要点

1. **告知与标识**：收银区应有监控告知（标识牌）。
2. **数据分级**：结构化事件（低敏）与原始视频（高敏）分级存储、分级访问。
3. **访问审计**：谁看了哪段视频要有日志。
4. **默认本地**：云端仅接收脱敏后的事件与必要片段。

## 常见陷阱

1. **默认上云存全程视频**：合规风险与成本双高。
2. **顺手做人脸**："既然有摄像头"——这是红线，坚决不做。
3. **留存无期限**：视频无限期留存是常见违规点。
